# Sologix Energy — Mobile Application

Expo React Native mobile application for the Sologix Energy workforce attendance platform, styled with NativeWind in a Light Solar Theme.

## Features
- **Offline-First Attendance**: Local SQLite outbox stores check-in, check-out, and telemetry points before syncing.
- **Persistent Location Engine**: Background GPS tracking with Android foreground service notification.
- **Hardware Status Monitoring**: Automatic detection and warning banner when device location services or permissions are disabled.
