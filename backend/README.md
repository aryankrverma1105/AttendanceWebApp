# Sologix Attendance API

Backend engine for **Sologix Energy** workforce attendance and operations platform.
Built with Bun, Express, Prisma, PostgreSQL, and Socket.IO.

Designed and developed by Aryan Kumar Verma for Sologix Energy.

## Setup & Run

To install dependencies:

```bash
bun install
```

To run development server:

```bash
bun run dev
```

To generate Prisma client:

```bash
bun run postinstall
```
