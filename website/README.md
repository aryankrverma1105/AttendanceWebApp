# Sologix Energy — Admin Web Dashboard

Next.js 16 admin web dashboard for the Sologix Energy workforce attendance platform, styled with a Light Solar Theme, Tailwind CSS v4, and shadcn/ui.

## Features
- **Solar Operations Radar**: Real-time Leaflet map displaying active field personnel, amber solar markers, pulsating red location-off alerts, and soft amber geofences.
- **Attendance & Duty Management**: Real-time attendance records, daily work logs, manual check-in/out records, and CSV export.
- **Workforce Administration**: Role-based access control (`ADMIN`), employee creation, password resets, and session revocations.
